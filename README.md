# pfin-analyzer（家計アナライザ）

家計簿アプリの CSV（マネーフォワード ME / Zaim / 銀行・カード明細）、iPhone アプリ（MoneyNote など）の表形式 PDF、または手書きメモを読み込み、
収支・分類別支出・固定費・前月比などをブラウザ内で分析する単一ファイルのアプリ。

- `index.html` だけで動作（外部送信なし。フォントのみ Google Fonts）
- UTF-8 / Shift_JIS を自動判定、列は自動推定（画面で変更可）
- メモ形式: `10/3 ランチ 850`、収入は `+280000` または「給料」を含める
- PDF は iOS の日本語フォント(Adobe-Japan1)の文字コードを内蔵テーブルで復元して読み取る（ブラウザ内で完結）
- 貯金・積立・NISA などは支出に含めず、貯蓄として別に数える
- 今日より先の日付の明細は「予定」として既定では集計から外す
